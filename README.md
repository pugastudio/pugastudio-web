# Puga Studio · sitio web

Sitio estático de Puga Studio. No necesita compilarse.

- `contenido.js`: todos los textos, proyectos y fotos del sitio.
- `img/`: fotos y logo. Las fotos de cada proyecto van en `img/proyectos/<nombre-del-proyecto>/`.
- `index.html`, `estilos.css`, `sitio.js`: estructura, diseño y movimiento.
